Streamlit Cloud'da bellek limiti hatası alıyorsanız, local'de çalıştırın.

───────────────────────────────────────────────────────────────
📋 ADIM 1: FastAPI'yi Başlat (Terminal 1)
───────────────────────────────────────────────────────────────

cd /Users/berhankiyanus/Desktop/Finance
. venv/bin/activate
venv/bin/python3 -m uvicorn api.main:app --reload --host 127.0.0.1 --port 8000

Veya script ile:
bash BASLAT_DIRECT.sh

✅ Başarılı olursa: "INFO: Uvicorn running on http://127.0.0.1:8000"

───────────────────────────────────────────────────────────────
📋 ADIM 2: Streamlit'i Başlat (Terminal 2 - YENİ PENCERE)
───────────────────────────────────────────────────────────────

cd /Users/berhankiyanus/Desktop/Finance
. venv/bin/activate
streamlit run app.py

Veya script ile:
bash BASLA_LOCAL.sh

✅ Başarılı olursa: "Local URL: http://localhost:8501"
